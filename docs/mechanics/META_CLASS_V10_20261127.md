# V10 competitive and class terrain screen

Status: candidate test harness, not yet executed. Baseline merged V10 3a3b8bf; prior V9 targeted screen #217, prior V10 elimination comparison #218. PR #221.

## Method

Run `node --test tools/test_meta_class_v10.mjs` from the repository root. The harness imports actual production combat and snapshots. Max benchmark: 3700 productive hours, S Masterwork, class/selected stance/teamwork 50, both teams, no raid bonuses. Eight environments, fixed mirrored seeds.

- 16 competitive/ablation teams, 120 unordered pairs, four seeds per orientation per zone = 7680 bouts.
- Independent siege confirmation against six mixed opponents, 12 seeds per orientation per zone = 1152 bouts.
- Same-role class substitution in a fixed seven-role team against melee, ranged and siege, two seeds per orientation per zone = 2976 bouts. All 31 classes. This tests contributions within one reference roster, not exhaustive class potential.
- Capture W/L/D, unresolved safety-limit outcomes, rounds, damage, healing, ability and control activity. Logs META_V10_ZONE, META_V10_SUMMARY, META_V10_CONFIRM_ZONE, META_V10_CONFIRM, CLASS_V10_ZONE and CLASS_V10_SUMMARY.
- Preference analysis: choose top-three zones on training matrix, apply the exact symmetric probability distribution from ARENA-PREFERENCES-001 (#219) to the pair-level results, and compare with uniform terrain. Use independent confirmation to test generalization where available. Reweighting is not additional battle simulation.
- A high or low win rate is diagnostic only; no hard meta or class uselessness can be proven by a finite roster sample. No automatic balance modifications. Progression tests are deferred until endgame combat is satisfactory.
